# Kapil B. Borkar — Portfolio Website

A responsive, single-page portfolio built with semantic HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build step or package installation is required. Google Fonts is loaded online; the page otherwise uses CSS artwork and text-based project visuals, so it does not depend on external image assets.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive layout, typography, colors and animations
- `script.js` — scroll reveal and mobile navigation
